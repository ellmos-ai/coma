1. PROJECT AND SUBPROCESS SCOPE
================================================================================

COMA is provided under the MIT license. pyproject.toml declares no direct
external Python runtime package dependencies (INV-COMA-02). This package
metadata does not cover the Python runtime, build tools, separately installed
agent CLIs, or provider services.

COMA uses configured local filesystem paths and starts provider CLIs as
subprocesses. Launched CLIs inherit the launching process's privileges and
environment and may contact providers or other services. COMA does not provide
network isolation, an air-gap guarantee, privilege dropping, or a security
isolation boundary.

One writer per channel is a caller protocol requirement. Optional role checks
are not OS locking or identity enforcement; callers coordinate concurrent
writes. Probe cleanup is best-effort and platform-dependent; descendant
termination is not guaranteed.

This inventory describes the project and listed Python packages only. It does
not determine license terms or legal status for separately installed agent
CLIs, provider services, the Python runtime, or other build and deployment
tools. Review those terms independently.
